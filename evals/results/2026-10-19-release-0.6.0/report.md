# v0.6.0 发布验收

本轮发布将需求开发与架构设计贯通，默认交付适用的需求拆分、每步功能与代码契约、技术架构图、
数据流图及实际验收；实现和审查使用相同工程标准。验收工具冻结原始/最终项目，逐项审查
必要成果，并以真实公共消费者验证产物。主技能与独立维护技能统一版本和安装事务。

## 内容及行为证据

发布版本为 `0.6.0`，不可变标签为 `v0.6.0`。本次仅整理版本、安装说明及发布记录，
运行入口、专题与维护指导保持与最终前向复测相同字节，见[身份核对](evaluated-guidance.json)。
源码、夹具、协议与原始历史证据沿用仓库现有分发方式，未静默改为最小运行包。

## 发布检查

[命令、环境及退出状态](checks.json)保留本轮实际输出；仓库 validator、主技能和维护技能
官方 quick_validate、确定性回归、核心暂存空白检查与完整暂存检查分别报告。
首次完整暂存空白检查 exit 2，共 1900 处提示，全部位于原始评测结果；核心源码检查 exit 0。
原始评测文件的历史空白警告保留原文，不格式化冻结证据或改写其哈希。
完整 71 例模型场景本轮未重跑，未宣称生成端已无遗漏或稳定无退化。

VERSION、维护技能 VERSION、CHANGELOG 首个版本与 README 当前发布标识统一为 0.6.0。
许可证继续为既有 MIT。发布标签应指向通过检查的提交；提交及标签推送后再次核对远端身份，
GitHub Release 使用同一标签和如实描述证据边界的说明。

## 安装维护

发布后通过官方 skill-installer 从固定 tag 暂存主技能与独立 companion，再用共同执行器
激活并验证文件摘要。旧本机预览完整备份；安装回执存于发现目录外，避免提交自引用。
此前评测报告中的“未发布”和本机临时路径保留为当时状态，不代表本轮发布失败；
本机安装路径只能在原机器复核，公开行为结论由已入库的源码、快照及原始检查支持。

浏览器证据限 Chromium 与 HTTP 替身；插件开发检查证明 Vite SSR 重载，不证明所有宿主版本
或浏览器 HMR 页面应用。未覆盖真机、辅助技术、全部操作系统和完整兼容矩阵。
