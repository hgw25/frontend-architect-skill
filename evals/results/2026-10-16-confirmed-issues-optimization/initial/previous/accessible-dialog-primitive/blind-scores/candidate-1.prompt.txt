+# Headless Dialog primitive
+
+`@fixture/headless-dialog` is a React 18/19 modal-dialog primitive. It owns dialog
+state, accessibility semantics, focus, dismissal, portal timing, and nested-layer
+coordination. Products own copy, actions, layout, colors, motion, and scroll-lock
+policy.
+
+## Public API
+
+```tsx
+import { Dialog } from '@fixture/headless-dialog'
+
+<Dialog.Root defaultOpen={false} onOpenChange={(open) => {}}>
+  <Dialog.Trigger className="productButton">Edit profile</Dialog.Trigger>
+  <Dialog.Portal>
+    <Dialog.Overlay className="productOverlay">
+      <Dialog.Content className="productDialog">
+        <Dialog.Title>Edit profile</Dialog.Title>
+        <Dialog.Description>Update your public information.</Dialog.Description>
+        {/* Product fields and actions */}
+        <Dialog.Close className="productButton">Close</Dialog.Close>
+      </Dialog.Content>
+    </Dialog.Overlay>
+  </Dialog.Portal>
+</Dialog.Root>
+```
+
+DOM components forward their ref and presentation/event attributes, including
+`className`, `style`, and `data-*` styling hooks. Primitive-owned IDs and roles
+cannot be overridden because they connect the trigger and accessible name. The
+interactive pieces add `data-state="open|closed"`. Named
+exports (`DialogRoot`, `DialogContent`, and the rest) are available alongside the
+`Dialog.*` namespace.
+
+- `Root`: `open` + `onOpenChange` for controlled state, or `defaultOpen` for
+  uncontrolled state. Do not switch ownership during a mount.
+- `Portal`: mounts into `document.body` after hydration. Pass `container` for an
+  owned portal host; `null` intentionally defers mounting.
+- `Trigger` / `Close`: semantic buttons with composed click handlers. Calling
+  `preventDefault()` in a consumer click handler cancels the primitive action.
+- `Content`: modal semantics and focus ownership. `initialFocusRef` selects an
+  initial descendant; otherwise the first tabbable descendant, then the content,
+  receives focus. `onEscapeKeyDown` may prevent a dismissal for a real product
+  constraint.
+- `Title` and optional `Description`: provide stable `aria-labelledby` and
+  `aria-describedby` relationships. If a title cannot be rendered, supply an
+  explicit `aria-label` or `aria-labelledby` to `Content`.
+- `Overlay`: a primary-pointer click on the topmost overlay dismisses it. A press
+  that starts in content does not count as an outside click.
+
+The primitive supports standard light-DOM controls. Focus traversal into custom
+shadow roots is outside this package's current contract and can be added behind
+the focused `dialog/focus.ts` boundary if a product adopts them.
+
+## Implementation boundaries
+
+- `Dialog.tsx` owns the public composition, state contract, SSR-safe portal, ARIA
+  wiring, and lifecycle effects.
+- `dialog/focus.ts` owns tabbable discovery, initial focus, and Tab containment.
+- `dialog/layers.ts` is the per-document nested-dialog registry. Only its top
+  layer responds to Escape or outside dismissal; covered parent content becomes
+  inert and is restored when the child closes.
+- Product code owns all strings and actions. The primitive emits no visible copy
+  and imports no product CSS.
+
+The server renders triggers but defers an open portal until the first browser
+layout effect. The client's first render therefore matches the server, avoids
+accessing browser globals during SSR, and then mounts the modal without a
+hydration mismatch.
+
+## Release verification matrix
+
+| Contract | Required check |
+| --- | --- |
+| Type/public exports | strict TypeScript through `src/index.ts`; build declarations |
+| Package artifact | ESM library build with React/ReactDOM external and `npm pack --dry-run` |
+| SSR/hydration boundary | closed and initially-open server render without DOM access |
+| Uncontrolled state | trigger, close button, overlay, and Escape paths |
+| Controlled state | host owns outer example state; the same browser paths call `onOpenChange` |
+| Accessible name/description | role query plus `aria-modal` and accessible-description assertion |
+| Focus | initial focus, forward/backward wrap, programmatic escape recovery, trigger restoration |
+| Nested dialogs | child alone handles Escape; parent is inert; focus restores child then parent trigger |
+| Browser baseline | Chromium on every change; Firefox/WebKit before a supported-browser release |
+| Styling | consumer classes at narrow/wide and zoomed viewports; forced-colors review before release |
+
+Run `npm run check` for the repository checks. The host-owned acceptance check is
+`node scripts/check-dialog-contract.mjs`.
+
+## Incremental migration
+
+1. Publish a prerelease and wrap each legacy product Dialog behind its existing
+   product API. Move that product's strings, buttons, and classes into the wrapper;
+   map its state to `open`/`onOpenChange` or `defaultOpen`.
+2. Migrate the simplest product first. Compare its keyboard, outside-click, focus
+   return, and analytics behavior in browser tests; rollback is a wrapper import
+   change, not a simultaneous product rewrite.
+3. Migrate the products with nested dialogs next and delete their local document
+   listeners/focus traps only after the shared nested tests pass in that host.
+4. Migrate the final product, mark legacy implementations deprecated with the
+   replacement example and removal version, then remove them in a major release.
+5. Promote the package from prerelease after the supported React/browser matrix
+   and packed artifact pass in representative consumer builds.
+
+The old monolithic `title`/`description`/`triggerLabel` shape intentionally does
+not enter the primitive: retaining it would keep product content and structure in
+the shared behavior layer. Product wrappers provide the compatibility seam while
+teams move to composition.

+const focusableSelector = [
+  'a[href]',
+  'area[href]',
+  'button:not([disabled])',
+  'input:not([disabled]):not([type="hidden"])',
+  'select:not([disabled])',

+function isFocusable(element: HTMLElement) {
+  if (element.tabIndex < 0 || element.closest('[inert]')) return false
+
+  const style = element.ownerDocument.defaultView?.getComputedStyle(element)
+  return style?.display !== 'none' && style?.visibility !== 'hidden' && element.getClientRects().length > 0
+}
+
+export function getTabbableElements(container: HTMLElement) {
+  return Array.from(container.querySelectorAll<HTMLElement>(focusableSelector))
+    .filter(isFocusable)
+    .map((element, documentOrder) => ({ documentOrder, element, tabIndex: element.tabIndex }))
+    .sort((left, right) => {
+      const leftOrder = left.tabIndex === 0 ? Number.MAX_SAFE_INTEGER : left.tabIndex
+      const rightOrder = right.tabIndex === 0 ? Number.MAX_SAFE_INTEGER : right.tabIndex
+      return leftOrder - rightOrder || left.documentOrder - right.documentOrder
+    })
+    .map(({ element }) => element)
+}
+
+export function focusInitialElement(container: HTMLElement, preferred?: HTMLElement | null) {
+  const target = preferred && container.contains(preferred) && isFocusable(preferred)
+    ? preferred
+    : getTabbableElements(container)[0] ?? container
+
+  target.focus({ preventScroll: true })
+}
+
+export function containTabFocus(event: KeyboardEvent, container: HTMLElement) {
+  const tabbable = getTabbableElements(container)
+
+  if (tabbable.length === 0) {
+    event.preventDefault()
+    container.focus({ preventScroll: true })
+    return
+  }
+
+  const first = tabbable[0]
+  const last = tabbable[tabbable.length - 1]
+  const active = container.ownerDocument.activeElement
+
+  if (event.shiftKey && (active === first || !container.contains(active))) {
+    event.preventDefault()
+    last.focus({ preventScroll: true })
+  } else if (!event.shiftKey && (active === last || !container.contains(active))) {
+    event.preventDefault()
+    first.focus({ preventScroll: true })

+type DialogLayer = {
+  id: symbol
+  surface: HTMLElement
+}

+const layersByDocument = new WeakMap<Document, DialogLayer[]>()
+
+function updateLayerAccessibility(layers: DialogLayer[]) {
+  const topLayer = layers.at(-1)
+
+  for (const layer of layers) {
+    const isTopLayer = layer === topLayer
+    layer.surface.toggleAttribute('inert', !isTopLayer)
+    if (isTopLayer) layer.surface.removeAttribute('aria-hidden')
+    else layer.surface.setAttribute('aria-hidden', 'true')
+  }
+}
+
+export function registerDialogLayer(document: Document, layer: DialogLayer) {
+  const layers = layersByDocument.get(document) ?? []
+  layers.push(layer)
+  layersByDocument.set(document, layers)
+  updateLayerAccessibility(layers)
+
+  return () => {
+    const index = layers.indexOf(layer)
+    if (index !== -1) layers.splice(index, 1)
+    layer.surface.removeAttribute('inert')
+    layer.surface.removeAttribute('aria-hidden')
+    updateLayerAccessibility(layers)
+    if (layers.length === 0) layersByDocument.delete(document)
+  }
+}

+  return layersByDocument.get(document)?.at(-1)?.id === id
