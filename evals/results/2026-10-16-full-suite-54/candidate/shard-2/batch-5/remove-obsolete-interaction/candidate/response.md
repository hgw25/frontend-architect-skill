## 最小重构决策

保留公共可调高度抽屉，不修改其默认行为或公共契约；只删除会话面板对“中间停靠高度”的整条依赖链。

1. 将会话面板收敛为两个稳定状态：

   - 展开：始终占满当前可用高度。
   - 收起：复用项目已有的全高收起动画。

   拖动中的位移只是手势临时值，不再是持久化的面板高度。不要把 `sheetHeight` 改成一个固定全高数值继续维护。

2. 简化头部拖动：

   - 仅头部接受向下拖动。
   - 达到现有关闭距离或速度条件时，进入已有全高收起动画。
   - 未达到条件时，将临时位移弹回 `0`。
   - 删除“寻找最近停靠点”“回到 60%”“从 60% 继续拖动”等分支。
   - WebView 内容区的滚动和触摸仍归 WebView，不参与面板拖动。

3. 从会话面板调用链删除：

   - `sheetHeight` 状态及其初始化、更新和派生计算；
   - `heightListener` 的注册、通知和清理；
   - WebView 针对中间高度变化的测量、重绘或绘制补偿；
   - 专门服务上述行为的五个透传参数，包括对应类型声明、默认值、包装层参数和调用参数；
   - 60% 常量、停靠点判断以及已经隐藏的按钮残留处理。

   五个参数应沿调用链真正删除，不能改传固定值、`undefined` 或空回调，否则废弃机制仍可能运行。

4. WebView 改为普通填充布局，由面板最终可用空间直接约束。安全区、键盘避让或系统栏处理若有独立产品要求则保留，不能因为它们也涉及高度而一并删除。

5. 公共可调高度抽屉及其他页面保持原样：

   - 若 `heightListener` 属于公共抽屉能力，只取消会话面板的订阅，不删除公共能力。
   - 若五个参数也被其他页面直接使用，只从会话面板及其专属包装层移除。
   - 不为会话面板给公共抽屉新增 `disable60Percent`、`fixedMode` 一类兼容开关；项目已有全高收起路径，应直接复用该路径。

现实的后续变化也容易承接：以后若要调整关闭阈值，只改头部手势策略；若重新引入停靠点，则作为新需求接回公共可调抽屉，而不是复活当前残留链路。

## 验证计划

| 风险 | 验证方式 |
|---|---|
| 旧逻辑仍可达 | 搜索会话面板路径中的 `sheetHeight`、`heightListener`、60% 常量、五个参数及 WebView 补偿入口；确认定义、类型和调用均已删除 |
| 初次打开闪现中间高度 | 在真实运行环境录屏或逐帧检查首次打开，首个稳定画面即为全高 |
| 短拖误关闭或停在半途 | 从头部做多组短距离、慢速拖动，均应回弹至全高且不触发关闭回调 |
| 正常下拉无法收起 | 验证超过距离阈值和快速下甩两条路径，均复用已有收起动画，关闭回调只执行一次 |
| 手势被连续输入打断 | 回弹期间再次拖动、关闭期间重复拖动，确认不会跳到 60%、卡住或重复关闭 |
| WebView 仍被反复重绘 | 对比改造前后的高度事件和 WebView 布局/绘制记录；拖动时不再出现中间高度补偿调用 |
| WebView 交互回归 | 验证内容滚动、顶部滚动位置、链接/输入交互不会带动面板；只有头部可以下拉 |
| 环境尺寸变化 | 覆盖旋转、窗口尺寸变化、安全区和键盘出现/消失；面板重新填满可用区域，无缓存高度残留 |
| 公共抽屉受损 | 在至少一个仍使用可调高度的页面验证展开、中间停靠、拖动和监听通知仍正常 |
| 动画与无障碍回归 | 验证现有返回/关闭入口、焦点恢复及 reduced-motion 路径，按项目原有契约执行 |
| 静态回归 | 执行项目既有类型检查、lint、会话面板交互测试和公共抽屉测试；不新造测试框架 |

最值得固化的自动化用例是三个用户可见契约：打开即全高、短拖回弹、有效下拉关闭；再加一个公共抽屉仍可停靠的回归用例。这样既能证明废弃行为已退出，也能保护仍在使用的共享能力。
