项目为空，没有可修改的业务文件。建议在唯一调用处直接派生展示值，无需新增工具函数或依赖：

```tsx
const displayName = name?.trim() || '未命名';
```

渲染时使用：

```tsx
<span>{displayName}</span>
```

不要使用 `name?.trim() ?? '未命名'`，因为空字符串不会触发 `??` 回退。

验证以下输入即可：

- `null` → `未命名`
- `''` → `未命名`
- `'   '` → `未命名`
- `'  张三  '` → `张三`
- `'张三'` → `张三`

这是单一使用点的简单派生逻辑，不值得抽取 helper 或引入依赖。
