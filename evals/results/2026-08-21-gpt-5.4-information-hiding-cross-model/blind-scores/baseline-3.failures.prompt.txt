+# @frontend-architect-eval/feature-flags
+
+Typed public feature flags for Vite via `virtual:feature-flags`.
+
+## Usage
+
+```ts
+// src/public-flags.ts
+export const publicFlags = ['checkoutV2', 'theme'] as const
+```
+
+```ts
+// vite.config.ts
+import { fileURLToPath } from 'node:url'
+
+import { defineFeatureFlags, featureFlags } from '@frontend-architect-eval/feature-flags'
+import { defineConfig } from 'vite'
+
+import { publicFlags } from './src/public-flags'
+
+const root = fileURLToPath(new URL('.', import.meta.url))
+
+export default defineConfig({
+  root,
+  plugins: [
+    featureFlags(
+      defineFeatureFlags({
+        source: new URL('./flags.json', import.meta.url),
+        expose: publicFlags,
+      }),
+    ),
+  ],
+})
+```
+
+```ts
+// feature-flags.d.ts
+import type { InferFeatureFlags } from '@frontend-architect-eval/feature-flags'
+import type sourceFlags from './flags.json'
+import { publicFlags } from './src/public-flags'
+
+declare module '@frontend-architect-eval/feature-flags/virtual' {
+  interface FeatureFlagsRegistry extends InferFeatureFlags<typeof sourceFlags, typeof publicFlags> {}
+}
+```
+
+```ts
+// app code
+import { flags } from 'virtual:feature-flags'
+
+if (flags.checkoutV2) {
+  document.body.dataset.theme = flags.theme
+}
+```
+
+## Public API
+
+- `featureFlags(options)`: registers the Vite plugin and exposes only the allowlisted keys.
+- `defineFeatureFlags(options)`: preserves tuple literals for `expose`.
+- `InferFeatureFlags<Source, Exposed>`: derives the `virtual:feature-flags` payload type from a JSON schema plus the allowlist.
+- `@frontend-architect-eval/feature-flags/virtual`: ambient registry that consumers augment once.
+
+## Operational notes
+
+- Diagnostics fail fast on empty `expose`, duplicate keys, invalid JSON, missing keys, non-primitive values, and suspicious secret-like names.
+- Runtime code is generated through a virtual module, so dev, build, SSR, and HMR share the same loader path.
+- Source maps are emitted for the published package build (`dist/index.js.map`) and the virtual module returns an inline source map object referencing the JSON source file.
+- The plugin caches the parsed JSON by file content and invalidates the cache when Vite observes a source change.
+
+## Integration coverage
+
+- `npm run test:build`: verifies client bundles contain public flags and exclude server-only values.
+- `npm run test:dev`: verifies SSR/dev reloads after flag changes and still strips secrets.
+- `npm run test:diagnostics`: verifies actionable config failures.
+- `npm run test:package`: verifies packed artifacts include JS, declarations, and source maps.
+
+## Versioning
+
+- Additive public flags or new helper types: minor release.
+- Changing generated module shape or diagnostics semantics in a breaking way: major release.
+- Internal bug fixes with no contract changes: patch release.
