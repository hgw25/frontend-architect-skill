## 观察

A 选择直接改动、不写设计文档、不再次询问授权；先检查 token 作用域，避免全局修改
通用 token，采用适度视觉与交互检查，不新建测试框架。

B 选择页面草稿、请求状态所有者、响应适配函数三个职责，复用现有 HTTP 客户端。
请求身份限制成功、失败与收尾的生效；卸载使请求失效；重试用已提交查询。
验证明确包含 B 先返回、A 后返回，以及旧错误迟到、未提交输入、重试和卸载。
未来仅改响应字段时修改适配边界与契约样例，保留 UI 和竞态行为；没有提出通用仓储或缓存。

读取入口、architecture-and-code 与 module-boundaries，共两个专题，符合路由上限。
