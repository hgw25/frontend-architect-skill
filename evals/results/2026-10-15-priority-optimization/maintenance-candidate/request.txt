前端包已经两次发布了缺失类型入口的产物。有人建议在 frontend-architect 的每轮 指导里加入“必须再检查一次 types”。请审查下面的执行链，给出最小修复与验证方案， 判断还需要怎样维护技能指导。现有 check-package 能暴露缺失 types，输出非零退出码； 不需要实际发布、安装依赖或引入新检查框架。

输入材料：
package.json
{
  "scripts": {
    "build": "tsc -p tsconfig.build.json",
    "check-package": "node scripts/check-package.mjs",
    "check": "npm run build"
  }
}

.github/workflows/validate.yml
steps:
  - run: npm ci
  - run: npm run check

CONTRIBUTING.md
发布前运行 npm run check；包验收脚本为 scripts/check-package.mjs。
