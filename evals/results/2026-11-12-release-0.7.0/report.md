# v0.7.0 发布验收

2026-11-12。发布本轮已审查的成熟方法实现指导、业务驱动选型、整体工作流边界及
评测证据修复。主技能与独立维护技能版本统一为 `0.7.0`，不可变标签为 `v0.7.0`。
运行入口、专题和维护指导不因版本整理再次改变，身份核对见 `evaluated-guidance.json`。

## 内容与已有行为证据

- [成熟方法与具体实现](../2026-11-11-implementation-patterns/established-methods/report.md)、
  [依赖组合](../2026-11-11-implementation-patterns/dependency-composition/report.md)和
  [必要思想扩充](../2026-11-11-implementation-patterns/expanded-methods/report.md)保留实际来源、
  独立判断、实现产物及受保护检查。被替换的初版示例只作为历史输入保留。
- [业务驱动选型](../2026-11-12-business-driven-choices/report.md)保留窄规则的旧新指导对照、
  复杂搜索生命周期、资料确认以及服务语义边界检查；两组本已同样正确时不冒称新增收益。
- [整体工作流](../2026-11-12-workflow-boundaries/report.md)区分阶段义务、设计深度和用户
  交付终点；最后文字核对与较早实际生成分别保存，不重标为相同输入。
- [整体复审](../2026-11-12-whole-skill-review/post-workflow/report.md)的三个评测缺口及
  随后独立复核发现的同类归档问题，已由[证据一致性修复](../2026-11-12-evidence-integrity/report.md)
  关闭。独立 10 个坏输入变体全部在评分前拒绝，评分调用为零；正常单轮、双轮及
  无工作区/无缓存的新评分通过。旧资料检查绕过被拒绝，正常产品实现的类型和 15 项测试通过。

这些定向结果支持具体判断和已复现问题的修复，不能替代全部 84 项模型行为评测。
部分原生任务没有完整事件、准确模型 ID/effort 或标准两阶段盲评分；相应限制保留，
不补造为新 CLI 协议下的有效评分，也不宣称所有场景稳定无退化或保证每次生成优秀代码。

## 发布检查与分发

本轮命令、实际退出状态和环境见 `checks.json` 及对应原始日志。使用仓库 validator、
主技能与维护技能官方 quick_validate、完整确定性回归，并核对 VERSION、CHANGELOG
首项、README 当前发布引用和 MIT 许可证。最终发布提交及 tag 将再次与远端核对。

实际发布前仓库校验、两项官方校验和 126 项完整确定性回归全部通过；20 项指导文件
与最后已审查冻结输入逐字节一致。核心暂存空白检查 exit 0；首次完整暂存检查 exit 2，
共 91 处提示，均在本轮保存的原始评测工件内，原始输出见 `full-staged-diff-check.log`。
这些历史字节继续保留，不通过改写冻结证据消除提示。

源码、夹具、协议和原始历史证据继续按现有完整仓库方式分发；历史日志和冻结输入不
为消除空白提示而格式化，完整暂存检查与核心源码检查分别报告。安装、更新及回滚仍
通过独立维护技能，使用固定发布标签和既有事务执行器；本次发布不自动修改本机安装。

GitHub Release 的正文见 [release-notes.md](release-notes.md)，包括本次变化、实际验证及
旧采集需要重新运行的兼容边界。浏览器、真机、真实后端和多模型全量对照本轮没有重跑。
