# 新维护者接手：独立控制提交资格

在现有实现上增加字段属性 `submit?: boolean`，默认提交。`submit: false` 的字段
仍参与 required 和自定义校验，但不进入发送 payload；disabled 仍排除校验和提交。
一个字段的校验器应继续收到完整原始 values，不能因另一个字段不提交就看不到它。
保持原有返回值、错误文本、拒绝传播和不修改输入的契约。

你没有首轮对话。只根据仓库，修改前简述当前数据流与预计改动位置；完成后运行
全部检查，更新 README 的公共契约说明。只能修改 src 和 README.md，不修改已有测试
或 package.json。不需要创建新的规则框架。
